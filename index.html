۱. مقدمه و نواحی کاری

ساختار BJT (npn)
نماد مداری npn و pnp
ناحیهBEBCشرط
فعالمستقیممعکوسVBE=0.7, VCE>0.2
اشباعمستقیممستقیمVCE≈0.2
قطعمعکوسمعکوسIB=0
IE = IC + IB | IC = β·IB | IE = (β+1)·IB

۲. درسنامهٔ DC با شماتیک

۱) بایاس ثابت

مدار اصلی
حلقه‌های KVL (BE + CE)
KVL حلقهٔ BE (ساعتگرد از VCC): −VCC + IBRB + VBE = 0 → IB = (VCC−0.7)/RB
KVL حلقهٔ CE: −VCC + ICRC + VCE = 0 → VCE = VCC − ICRC

۲) امیتر-استابلایز (RB + RE)

مدار اصلی
حلقه‌های KVL
KVL حلقهٔ BE: −VCC + IBRB + VBE + IERE = 0
با IE=(β+1)IB → IB = (VCC−0.7)/[RB+(β+1)RE]
KVL حلقهٔ CE: VCE = VCC − IC(RC+RE)

۳) تقسیم ولتاژ

مدار اصلی (R1, R2, RC, RE)
معادل تونن
RTH = R₁‖R₂ ، VTH = R₂/(R₁+R₂)·VCC
IB = (VTH−0.7)/[RTH+(β+1)RE] ، VCE = VCC − IC(RC+RE)

۴) فیدبک کلکتور

RB بین C و B
IB = (VCC−0.7)/[RB+β(RC+RE)]

۵) PNP

PNP (VEB=0.7)

۳. مثال‌های DC با شماتیک

📁دستهٔ ۱: بایاس ثابت
مثال DC-1 ⭐ ساده
🔧 ویژگی‌های مدار: RB=470k RC=3k بدون RE
شماتیک مدار
جهت KVL (BE و CE)
داده: VCC=15V, RB=470kΩ, RC=3kΩ, β=80
مطلوب: IB, IC, VCE
قدم ۱ — KVL حلقهٔ BE (ساعتگرد)
↻ BE Loop از VCC شروع، به سمت RB، سپس BE
−VCC + IB·RB + VBE = 0
IB = (15−0.7)/470k = 30.4 µA
قدم ۲ — KCL در ترانزیستور
→ KCL جریان ورودی بیس
IC = β·IB = 80 × 30.4µ = 2.43 mA
قدم ۳ — KVL حلقهٔ CE
↻ CE Loop از VCC به RC به کلکتور
VCE = 15 − 2.43m×3k = 7.71 V
IB=30.4 µA، IC=2.43 mA، VCE=7.71 V (فعال)
